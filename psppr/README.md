# Логическая экспертная система анализа пользовательских сессий

Практическая работа №1 по проектированию систем поддержки принятия решений.
Python 3.10+, без внешних зависимостей.

## Запуск

```bash
cd logic_project
python main.py
```

Введите `help` для полного справочника команд.
Для автоматических тестов: `python -m unittest -v`.

## Быстрый пример

```text
alp(a, высокая частота запросов)
alp(b, подозрительный User-Agent)
alp(e, подозрительное поведение)
axi(a*b -> e)
fact(a, true)
fact(b, true)
theorem(e)
table(a -> b)
laws
```

Демонстрационные ситуации: `demo 1`, `demo 2`, `demo 3`.
Они соответствуют обычной блокировке, изменению ключевого признака
и конфликту явно ложного факта с логическим выводом.

## Формальная модель F = <A, S, Ak, P>

- **A** — идентификаторы высказываний, зарегистрированные командой `alp`.
- **S** — грамматика с операторами `!`, `*`, `+`, `->` и скобками;
  лексер и рекурсивный синтаксический анализатор.
- **Ak** — произвольные булевы ограничения, включая дизъюнкты Хорна
  вида `a*b -> c`, зарегистрированные командой `axi`.
- **P** — правило заключения (modus ponens) с прямым выводом
  для положительных правил Хорна и проверка логического следования через SAT.

Полные булевы формулы поддерживаются в `axi`, `theorem`, `eval` и `table`.
Команда `check` проверяет выполнимость базы знаний, а `simplify`
применяет несколько законов булевой алгебры.
Движок использует преобразование Цейтина в КНФ и алгоритм DPLL.

## Файлы

- `lexer.py`: разбиение выражения на токены и ошибки символов;
- `parser.py`: построение дерева выражения с приоритетом операций;
- `logic.py`: вычисление, таблицы истинности, проверка 14 законов;
- `knowledge_base.py`: алфавит, уникальные номера аксиом и факты;
- `inference.py`: прямой вывод, трассировка, конфликтные факты;
- `solver.py`: общий SAT-решатель для произвольных высказываний;
- `main.py`: консольный язык и три сценария;
- `test_logic.py`: автоматические проверки.

## Логические ограничения

Недоказанность не равна ложности. Результаты проверки теорем:
`TRUE` — теорема следует из базы; `FALSE` — её отрицание следует;
`UNKNOWN` — база допускает оба варианта; `INCONSISTENT` —
база знаний противоречива. Для `UNKNOWN` и `FALSE`
показывается контрпример. Произвольные формулы обрабатывает SAT-решатель,
а трассировка modus ponens применяется только к положительным правилам
Хорна. SAT-вывод не сопровождается пошаговым формальным доказательством.
